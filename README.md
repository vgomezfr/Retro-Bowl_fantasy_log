This repository contains two files:
1. main.py: Contains the code for the interactive terminal. Run this file to start up the terminal and use all its features.
2. retro_bowl_fantasy_stats.py: This file contains all the necessary functions for interacting with player data.

Use tips:
  1. Make sure to have both files in the same folder/directory: main.py needs to be able to access all the functions in retro_bowl_fantasy_stats.py
  2. When using the terminal, make sure to only enter one of the given options. In some cases, the terminal will discard invalid inputs and ask for new input, but in other cases it may crash.
  3. Always exit the terminal properly by entering "E". This may require you to navigate to a menu where "E" is a valid input.
  4. If the terminal crashes, ALL NEW DATA FROM THAT SESSION WILL BE LOST. Saving occurs only after a successful terminal close.

Enjoy chronicling and remembering your favorite players!
